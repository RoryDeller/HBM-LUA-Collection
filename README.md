All contents in HBM are OpenComputer program ideas in a game simulation called Nuclear Tech mod. All on a minecraft singleplayer world.

All individuals scripts fit into a either esoteric Assembly called the Autocal or servers/computer cases in Minecraft to capture data points/values in power generators and/or Nuclear powerplant controlled outputs to be displayed on a graphical monitor.

All scripts are written exclusively in LUA. Continuing this work requires a bridge into python of some sort. Perhaps an API?
